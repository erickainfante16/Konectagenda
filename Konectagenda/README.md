## 🌟 Sobre el proyecto

**Konectagenda** es una aplicación de agenda telefónica desarrollada en Java que permite administrar contactos de manera sencilla, práctica y organizada.

Este proyecto fue realizado en equipo durante un **hackathon del Bootcamp de Generation México, Cohorte 74**, como parte de una experiencia de aprendizaje enfocada en el desarrollo de software, la programación orientada a objetos, la colaboración y el uso de herramientas de trabajo profesional.

Nuestro objetivo es crear una aplicación que facilite la gestión de contactos y, al mismo tiempo, fortalecer nuestras habilidades técnicas y colaborativas como desarrolladores.

---

## 🎯 Objetivo

Desarrollar una aplicación de consola para gestionar contactos telefónicos, aplicando principios de programación orientada a objetos, estructuras de datos, control de versiones y metodologías ágiles.

## 🏗️ Arquitectura del proyecto

Konectagenda está organizado mediante clases que separan la información de los contactos, la gestión de la agenda y la ejecución de la aplicación.

### 📂 Estructura de directorios

```text
Konectagenda/
│
├── src/
│   └── org/
│       └── generation/
│           └── mx/
│               ├── modelo/
│               │   ├── Contacto.java
│               │   └── Agenda.java
│               │
│               ├── servicio/
│               │   └── servicios de gestión
│               │
│               └── Main.java
│
├── .gitignore
└── README.md
```

### 📦 Organización

| Componente | Responsabilidad |
|---|---|
| `modelo` | Representar las entidades principales del sistema. |
| `servicio` | Gestionar la lógica y las operaciones de la aplicación. |
| `Main` | Iniciar el programa y administrar la interacción con el usuario. |

## 🧩 Diseño de clases

### 📇 `Contacto`

Representa a una persona almacenada en la agenda telefónica.

**Atributos:**

| Atributo | Tipo | Descripción |
|---|---|---|
| `nombre` | `String` | Nombre del contacto. |
| `apellido` | `String` | Apellido del contacto. |
| `numero` | `int` | Número telefónico. |

**Métodos:**

- Constructor vacío.
- Constructor con parámetros.
- `getNombre()` / `setNombre()`
- `getApellido()` / `setApellido()`
- `getNumero()` / `setNumero()`
- `toString()`

La clase aplica el principio de **encapsulamiento**, manteniendo sus atributos privados y proporcionando métodos públicos para acceder y modificarlos.

### 📒 `Agenda`

Se encarga de administrar la colección de contactos y sus operaciones.

**Estructura de almacenamiento:**

- `HashMap` para almacenar y organizar los contactos.

**Métodos principales:**

| Método | Descripción |
|---|---|
| `añadirContacto(Contacto c)` | Agrega un contacto. |
| `existeContacto(Contacto c)` | Verifica si el contacto existe. |
| `listarContactos()` | Muestra los contactos registrados. |
| `buscaContacto(String nombre)` | Busca un contacto por nombre. |
| `eliminarContacto(Contacto c)` | Elimina un contacto. |
| `modificarTelefono(String nombre, String apellido, String nuevoTelefono)` | Modifica el teléfono de un contacto. |
| `agendaLlena()` | Verifica si la agenda está llena. |
| `espaciosLibres()` | Consulta los espacios disponibles. |

### 🖥️ `Main`

Es la clase principal del sistema y contiene el método de entrada `main`.

**Responsabilidades:**

- Iniciar la aplicación.
- Mostrar el menú principal.
- Recibir las opciones del usuario.
- Gestionar la navegación.
- Coordinar las operaciones de la agenda.

## 🌿 Flujo de trabajo con Git

Para mantener una organización eficiente y facilitar el trabajo colaborativo, el equipo utiliza una estructura jerárquica de ramas.

### 🌳 Jerarquía de ramas

```text
main
└── develop
    │
    ├── feature/interfaz
    │   ├── branch/interfaz/eri
    │   ├── branch/interfaz/kevin
    │   ├── branch/interfaz/dani
    │   └── branch/interfaz/axeel
    │
    ├── feature/agenda
    │   └── branch/agenda/<integrante>
    │
    └── feature/contacto
        └── branch/contacto/ericka
```

### 🔀 Descripción de ramas

| Rama | Propósito |
|---|---|
| `main` | Versión estable y final del proyecto. |
| `develop` | Rama de integración de las funcionalidades. |
| `feature/interfaz` | Desarrollo de la interfaz y navegación. |
| `feature/agenda` | Desarrollo de las operaciones de la agenda. |
| `feature/contacto` | Desarrollo de las funcionalidades de contacto. |
| `branch/<feature>/<integrante>` | Desarrollo individual de tareas asignadas. |

### 🏷️ Convención de nombres

Las ramas individuales siguen el formato:

```text
branch/<feature>/<integrante>
```

**Ejemplos:**

```text
branch/contacto/ericka
branch/interfaz/eri
branch/interfaz/kevin
branch/interfaz/dani
branch/interfaz/axeel
branch/agenda/<integrante>
```

### 🔄 Proceso de integración

1. Actualizar la rama `develop`.
2. Crear o cambiar a la rama individual asignada.
3. Desarrollar la funcionalidad correspondiente.
4. Registrar los cambios mediante commits descriptivos.
5. Subir la rama al repositorio remoto.
6. Crear un Pull Request hacia la rama `feature` correspondiente.
7. Revisar e integrar las contribuciones de los integrantes.
8. Consolidar las funcionalidades en `develop`.
9. Validar el funcionamiento del sistema integrado.
10. Integrar la versión final en `main`.

### 💡 Ejemplo de comandos Git

```bash
# Cambiar a develop
git checkout develop

# Actualizar develop
git pull origin develop

# Crear rama individual
git checkout -b branch/contacto/ericka

# Agregar cambios
git add .

# Crear commit
git commit -m "feat: implementa funcionalidades de contacto"

# Subir rama al repositorio remoto
git push -u origin branch/contacto/ericka
```

## 🚀 Instalación y ejecución

### 📋 Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- Java JDK.
- IntelliJ IDEA.
- Git.

### 1️⃣ Clonar el repositorio

Abre una terminal y ejecuta:

```bash
git clone https://github.com/erickainfante16/Konectagenda.git
```

### 2️⃣ Abrir en IntelliJ IDEA

1. Abre IntelliJ IDEA.
2. Selecciona **Open**.
3. Localiza la carpeta `Konectagenda`.
4. Selecciona la carpeta del proyecto.
5. Espera a que el IDE cargue los archivos.

### 3️⃣ Configurar el JDK

1. Dirígete a **File > Project Structure**.
2. Selecciona **Project**.
3. Configura el JDK instalado y compatible con el proyecto.
4. Guarda los cambios.

### 4️⃣ Ejecutar la aplicación

1. Abre el archivo `Main.java`.
2. Localiza el método `main`.
3. Haz clic en el ícono ▶️ junto a la clase o método.
4. Selecciona **Run 'Main'**.
5. Utiliza la consola de IntelliJ IDEA para interactuar con la aplicación.

## 🤝 Metodología colaborativa

El equipo organiza sus actividades mediante un tablero **Kanban**, facilitando la visualización de tareas, la asignación de responsabilidades y el seguimiento del trabajo.

### Herramientas de organización

- **GitHub Issues:** descripción y seguimiento de actividades.
- **GitHub Projects:** tablero Kanban del equipo.
- **Branches:** desarrollo independiente de funcionalidades.
- **Pull Requests:** revisión e integración de código.
- **Discord:** comunicación y coordinación.

### Buenas prácticas

- Mantener commits claros y descriptivos.
- Respetar la estructura de ramas establecida.
- Trabajar en la rama asignada.
- Revisar el código antes de integrarlo.
- Evitar sobrescribir el trabajo de otros integrantes.
- Mantener comunicación constante.
- Validar que el código compile y funcione correctamente.
